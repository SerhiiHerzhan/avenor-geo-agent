# Avenor Cars — индексируемая версия

Обновлено 7 октября 2026 года. Сайт для https://stowarszawa.com/. Русская главная рассчитана на запросы «сто варшава» и «автосервис варшава».

## Загрузка на хостинг

Скачайте `avenor-hosting-production.zip` и распакуйте его в корневую папку домена. Файл `index.html` должен находиться непосредственно в корне, рядом с папками `assets`, `ua`, `pl`, а также `robots.txt`, `sitemap.xml` и `404.html`. Подробные шаги — в `HOSTING.md`.

Текущий `dist/` и оба hosting-архива содержат production: индексация разрешена для трёх языковых главных. Публичное размещение на хостинге в рамках этой задачи не выполнялось.

## Реализовано

- Статические HTML-страницы RU `/`, UK `/ua/` с `lang="uk"`, PL `/pl/`.
- Адаптивная главная: услуги, цены, гарантия, обращение, специализация, FAQ, контакты.
- Адрес Chełmżyńska 5, 04-247 Warszawa, ссылки на Google Maps и построение маршрута.
- Телефон +48 453 225 773; звонок и SMS открывают соответствующее приложение пользователя.
- Цены: диагностика 100 zł, работа по замене масла 150 zł, нормо-час 250 zł. Условия и VAT уточняются при записи; стоимость материалов не выдумана.
- Гарантия: 6 месяцев на работы, 12 на запчасти. Применимость и условия согласуются при обращении.
- Часы: Пн–Пт 09:00–19:00, Сб 09:00–12:00. Режим воскресенья в исходных данных не указан.
- Title, description, один H1, self-canonical, взаимные hreflang ru/uk/pl/x-default.
- WebSite и AutoRepair JSON-LD с адресом, телефоном, картой и часами. Вымышленных рейтингов, отзывов и координат нет.
- Production robots.txt и sitemap.xml. Страница 404 имеет noindex и исключена из sitemap.
- Полный контент в исходном HTML. Сторонние ресурсы, трекеры и зависимости сборки отсутствуют.

## Сборка и проверка

Для редактирования и сборки нужен Python 3.12+. Для статического публичного хостинга Python не требуется.

```bash
python build.py
python serve.py --port 8000
```

При работающем локальном сервере:

```bash
python verify.py
```

Для другого порта:

```bash
python serve.py --port 8001
python verify.py --base-url http://127.0.0.1:8001
```

`python build.py` и `python build.py --production` создают индексируемую версию. `python build.py --staging` создаёт закрытый предпросмотр: noindex,nofollow, robots Disallow и пустой sitemap.

## Редактирование

- `locales.json`: переводы и тексты трёх языков.
- `business.json`: адрес, телефон, часы и домен.
- `build.py`: шаблон и SEO-разметка.
- `public/assets/site.css`: дизайн и адаптивность.
- `public/assets/site.js`: мобильное меню.
- `public/assets/*.svg`: декоративная иллюстрация и фавикон.

Изменяйте исходники, затем собирайте сайт. Прямые правки в `dist/` будут перезаписаны.

## Проверки

Production и staging сборки, HTTP-маршруты, ссылки, ресурсы, UTF-8, метаданные, canonical/hreflang, JSON-LD, адрес и URL карт проверены через `verify.py`. Браузерная проверка Chromium выполнена для трёх языков на ширинах 320/390/768/1440. Переполнений и ошибок браузера нет; меню и FAQ работают.

Результаты находятся в `qa/verification-summary.json` и `qa/production-browser-review.json`. Hosting-архив проверен на целостность, наличие index.html в корне, открытые robots и состав sitemap.

Публичный хостинг, DNS/HTTPS/CDN, Search Console, полевые Core Web Vitals, доставка звонков/SMS и фактическое попадание в индекс или позиции не проверялись. Формы заявок с серверной отправкой нет: доступны звонок и SMS.
