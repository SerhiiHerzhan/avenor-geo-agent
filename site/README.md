# Avenor Cars — индексируемая версия

Обновлено 8 октября 2026 года после публичного аудита RalCar, RemZone и TITAN. Сайт для https://stowarszawa.com/. Русская главная рассчитана на запросы «сто варшава» и «автосервис варшава».

## Загрузка на хостинг

Скачайте `avenor-hosting-production.zip` и распакуйте его в корневую папку домена. Файл `index.html` должен находиться непосредственно в корне, рядом с папками `assets`, `ua`, `pl`, а также `robots.txt`, `sitemap.xml` и `404.html`. Подробные шаги — в `HOSTING.md`.

Текущий `dist/` и оба hosting-архива содержат production: индексация разрешена для 15 страниц: трёх языковых главных и 12 страниц услуг. Публичное размещение на хостинге в рамках этой задачи не выполнялось.

## Реализовано

- Статические HTML-страницы RU `/`, UK `/ua/` с `lang="uk"`, PL `/pl/`.
- Адаптивная главная: услуги, цены, гарантия, обращение, специализация, FAQ, контакты.
- Подробные страницы диагностики, масла и ТО, подвески и тормозов на RU/UK/PL: симптомы, объяснение проверки, стоимость и ограничения, подготовка к визиту, FAQ, запись.
- Навигация «главная → услуга», хлебные крошки, оглавление и связанные услуги. Языковой переключатель сохраняет выбранную услугу.
- Адрес Chełmżyńska 5, 04-247 Warszawa, ссылки на Google Maps и построение маршрута.
- Телефон +48 453 225 773; звонок и SMS открывают соответствующее приложение пользователя.
- Цены: диагностика 100 zł, работа по замене масла 150 zł, нормо-час 250 zł. Условия и VAT уточняются при записи; стоимость материалов не выдумана.
- Гарантия: 6 месяцев на работы, 12 на запчасти. Применимость и условия согласуются при обращении.
- Часы: Пн–Пт 09:00–19:00, Сб 09:00–12:00. Режим воскресенья в исходных данных не указан.
- Title, description, один H1, self-canonical, взаимные hreflang ru/uk/pl/x-default.
- WebSite, WebPage и AutoRepair JSON-LD с адресом, телефоном, картой и часами; на услугах дополнительно Service и BreadcrumbList. Вымышленных рейтингов, отзывов и координат нет.
- Production robots.txt и sitemap.xml. Страница 404 имеет noindex и исключена из sitemap.
- Полный контент в исходном HTML. Сторонние ресурсы, трекеры и зависимости сборки отсутствуют.

## Источник данных

Полный адрес владелец сообщил в чате. Телефон, марки, услуги, BMW ISTA/Launch, часы, цены и гарантийные сроки взяты из пользовательского брифа по прямому запросу подготовить версию с имеющимися данными под индексацию. Независимая проверка коммерческих условий не проводилась; неизвестные детали VAT, состава диагностики и акций не выдуманы.

Название административного района Rembertów убрано: точный адрес подтверждён, район по этому адресу независимо не проверен. Оригинальный логотип и пять PNG упомянуты в документе, но сами файлы не предоставлены. Иллюстрация автомобиля декоративная и не выдаётся за фотографию работы сервиса.

## Сборка и проверка

Для редактирования и сборки нужен Python 3.12+. Для статического публичного хостинга Python не требуется.

```bash
python build.py
python serve.py --port 8000
```

При работающем локальном сервере:

```bash
python verify.py
```

Для другого порта:

```bash
python serve.py --port 8001
python verify.py --base-url http://127.0.0.1:8001
```

`python build.py` и `python build.py --production` создают индексируемую версию. `python build.py --staging` создаёт закрытый предпросмотр: noindex,nofollow, robots Disallow и пустой sitemap.

## Редактирование

- `locales.json`: переводы и тексты главных трёх языков.
- `services.json`: подробные тексты четырёх услуг на каждом языке.
- `package.py`: создание hosting-архивов и архива исходников.
- `SEO-COMPETITORS.md`: сравнение конкурентов, источники, приоритеты.
- `audits/`: отдельные отчёты трёх конкурентов; `qa/competitor-audit-evidence.json`: даты, HTTP-статусы и SHA-256 ответов.
- `business.json`: адрес, телефон, часы и домен.
- `build.py`: шаблон и SEO-разметка.
- `public/assets/site.css`: дизайн и адаптивность.
- `public/assets/site.js`: мобильное меню.
- `public/assets/*.svg`: декоративная иллюстрация и фавикон.

Изменяйте исходники, затем собирайте сайт. Прямые правки в `dist/` будут перезаписаны.

## Проверки

Production и staging сборки, HTTP-маршруты, ссылки, ресурсы, UTF-8, метаданные, canonical/hreflang, JSON-LD, адрес и URL карт проверены через `verify.py`. Браузерная проверка Chromium выполнена для всех 15 страниц на ширинах 320/390/768/1440. Переполнений и ошибок браузера нет; меню и FAQ работают.

Результаты находятся в `qa/verification-summary.json` и `qa/production-browser-review.json`. Hosting-архив проверен на целостность, наличие index.html в корне, открытые robots и состав sitemap.

Публичные GET выполнены 8 октября: главная stowarszawa.com вернула 403, sitemap.xml — 404, robots.txt — 200. Robots хостинга разрешает общий обход, но отдельно запрещает ряд ботов, включая Claude-SearchBot и PerplexityBot. Это состояние публичного домена, не готового архива. Причина 403 и доступ настоящего Googlebot не установлены; DNS/CDN, Search Console, полевые Core Web Vitals, доставка звонков/SMS и фактические позиции не измерялись. Формы заявок с серверной отправкой нет: доступны звонок и SMS.

После успешной проверки production-сборки выполните `python package.py`: ZIP для хостинга содержит только статические файлы с index.html в корне. Отчёты и исходники в hosting ZIP не попадают.
