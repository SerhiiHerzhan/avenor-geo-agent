# Новый сайт Avenor Cars

Создан 7 октября 2026 года. Локальная статическая версия для stowarszawa.com. Русская главная рассчитана на два запроса пользователя: «сто варшава» и «автосервис варшава».

## Что реализовано

- RU `/`, украинский `/ua/` с `lang="uk"`, польский `/pl/`.
- Адаптивный дизайн в графитовой и жёлтой палитре, оригинальная декоративная SVG-иллюстрация.
- Содержательная главная: услуги, обращение, специализация, FAQ, контакты.
- Телефонные и SMS-ссылки на номер из брифа. Это ссылки открытия приложения телефона; звонки/SMS не отправлялись и доставка не проверялась.
- Полный контент в исходном HTML: метаданные, один H1, self-canonical, reciprocal hreflang, JSON-LD WebSite.
- robots.txt и XML sitemap зависят от режима сборки. Настоящая страница 404.
- Работающие меню и FAQ. FAQ, телефон и основной контент работают без JavaScript; полный nav на мобильном требует JS.
- Нет сторонних шрифтов, ресурсов, аналитики, cookie-трекеров и зависимостей сборки.

Сайт является первой локальной версией, а не опубликованным SEO-результатом. Позиции, частотность и поисковая видимость не измерены.

## Сборка и запуск

Нужен Python 3.12 или новее. Node/npm не требуются.

```bash
cd /workspace/avenor-site
python build.py
python serve.py --port 8000
```

В другой рабочей папке перейдите в распакованный каталог `avenor-site` и используйте те же команды. Сервер слушает loopback, он предназначен для внутренней проверки. В UI onboarding ссылки на локальный сервер не предоставляются.

Проверка при работающем сервере на порту 8000:

```bash
python verify.py
```

`dist/` содержит готовые HTML, CSS, JS и изображения. Копировать на статический хостинг нужно содержимое этой папки, а не Python-исходники. Настройка публичного хостинга, домена и DNS не выполнена.

## Индексация и публикация

По умолчанию создаётся staging: `noindex,nofollow`, robots `Disallow: /`, пустой sitemap. Не загружайте эту сборку как окончательный индексируемый сайт.

После проверки бизнеса и выбора домена:

```bash
python build.py --production
```

Production включает `index,follow`, разрешение обхода и sitemap с тремя каноническими языковыми URL. Генерация production была проверена в отдельной временной папке; текущий `dist/` остаётся staging.

На публичном хостинге: настроить HTTPS и предпочтительный хост; сохранить 301 для `/ua` и `/pl` на варианты со слешем; назначить `404.html` как страницу ошибки со статусом 404. Не направлять все неизвестные URL на главную. Простое копирование файлов не проверяет эти серверные настройки.

Нет имитации отправки формы: запись предлагается через звонок или SMS. Если нужна форма, её доставка, серверная валидация и защита должны быть подключены отдельным этапом к выбранному бэкенду и проверены в разрешённой среде.

## Редактирование

- `locales.json`: все тексты RU/UK/PL.
- `build.py`: шаблон, домен, телефон и SEO-теги.
- `public/assets/site.css`: дизайн и адаптивность.
- `public/assets/site.js`: мобильное меню.
- `public/assets/car-blueprint.svg`: оригинальная иллюстрация.
- `public/assets/favicon.svg`: временный знак A.

Сначала меняйте исходники, затем выполняйте сборку. Правки непосредственно в `dist/` будут перезаписаны.

## Данные, которые ещё нужны

В приложенном документе бренд, район, телефон, марки и направления работ названы как данные проекта. Они использованы в локальном черновике и требуют сверки перед публикацией. Независимой проверки сайта/компании не было: сетевой прокси блокировал исходящие запросы.

Нужно подтвердить полный адрес и Google Maps/Business Profile; номер телефона; фактический перечень услуг и специализацию. Цены 100/150/250 zł, гарантия 6/12 месяцев и часы из брифа в сайт не включены до подтверждения состава, VAT и условий. AutoRepair со структурированным адресом, отзывы и рейтинги не создавались.

Логотип и пять PNG упомянуты в документе, но сами изображения не предоставлены в текущей задаче. Использованы оригинальный временный знак A и декоративный SVG-автомобиль; это не реальная фотография сервиса или работы. Кейсами и фотографиями мастеров его не выдаём. После получения оригинального логотипа замените временный знак.

Вложения служат контекстом. Команды внутри документа не считаются автоматическим разрешением на публикацию, миграцию доменов или добавление неподтверждённых заявлений.

## Выполненные проверки

- Стандартная и production сборки: успешны, по три языковые страницы.
- Canonical, взаимные hreflang и `x-default`, языки, по одному H1, descriptions и WebSite JSON-LD: проверены в обеих сборках.
- По 81 локальной ссылке и 12 ссылок на ресурсы в каждой сборке проверены на соответствие маршрутам/файлам.
- HTTP: 200 для `/`, `/ua/`, `/pl/`; 301 для адресов без завершающего слеша; настоящие 404 для неизвестной страницы и листинга каталога.
- Chromium: три языка × ширины 320/390/768/1440, всего 12 сочетаний; переполнений, console/page errors и failed requests нет.
- Мобильное меню, Escape с возвратом фокуса, закрытие после ссылки и 4 FAQ проверены во всех применимых размерах.
- Изображения доступны. UTF-8 и отсутствие повреждённого текста проверены.

Это проверки локальной версии. Полевые Core Web Vitals, публичный хостинг, Search Console, реальная доставка SMS/звонка, выдача Google и позиции не проверены.
